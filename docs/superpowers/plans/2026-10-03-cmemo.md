# CMemo 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现 CMemo——通过 agent hook 记录所有 AI 对话 session，并在 macOS 应用中按 agent 筛选、按目录浏览、查看完整对话内容。

**Architecture:** CLI 落盘 + App 扫描（方案 A）。`cmemo` CLI 接收 hook 的 stdin JSON，追加写入 JSONL；`CMemoApp`（SwiftUI）扫描同一目录建内存索引，三栏展示，文件监听近实时刷新。两者经文件系统解耦。

**Tech Stack:** Swift 5.9 / SwiftPM（零第三方依赖）、SwiftUI（macOS 13+）、XCTest

**Spec:** `docs/superpowers/specs/2026-10-03-cmemo-design.md`

## Global Constraints

- Swift tools version 5.9；platforms `.macOS(.v13)`；**零第三方依赖**
- 存储目录：`~/Library/Application Support/CMemo/sessions/`（`SessionStore.defaultBaseDirectory()`）
- 协议字段 snake_case：`agent`/`session_id`/`cwd`/`role`/`content`/`timestamp`/`title`；必填前 5 个；`timestamp` 缺省补当前时间；`title` 可选
- `role` 仅 `user` | `assistant`
- 会话文件：`<agent>-<sanitized(session_id)>.jsonl`；sanitize 规则：仅保留字母数字与 `.` `-` `_`，其余替换为 `_`
- 文件首行 meta：`{"type":"meta","cwd":"...","created_at":"..."}`；后续每行一条统一协议 JSON
- 时间戳 ISO8601（JSONEncoder/Decoder `.iso8601` 策略）
- App 以 SPM executable 运行（`swift run CMemoApp`）；打包 .app bundle 范围外

## Review Focus

1. session_id 含 `/`、空格等特殊字符 → 文件名注入/路径穿越；期望：sanitize 后安全落在一个文件内（Task 2 测试钉住）
2. JSONL 存在损坏行（崩溃半行写入）→ 期望：跳过该行、summary 标记 `isCorrupted`、不崩溃（Task 3）
3. App 未运行期间 hook 多次触发 → 期望：追加不覆盖、不重复 meta 行（Task 2）
4. 空 stdin / 缺必填字段 → 期望：CLI 退出码 1、stderr 有信息、不产生文件（Task 5）
5. 单条消息超长（~1MB）→ 期望：完整落盘并完整读回，不截断（Task 2）

import Foundation
@testable import CMemoKit

final class SessionStoreReadTests: XCTestCase {
    private var dir: URL!
    private var store: SessionStore!
    override func setUpWithError() throws {
        dir = FileManager.default.temporaryDirectory
            .appendingPathComponent("cmemo-tests-\(UUID().uuidString)")
        try FileManager.default.createDirectory(at: dir, withIntermediateDirectories: true)
        store = SessionStore(baseDirectory: dir)

        let all = try store.scan()
        XCTAssertEqual(all.count, 1)
        XCTAssertTrue(all[0].isCorrupted)
        XCTAssertEqual(all[0].messageCount, 0)

    func testLoadMessagesSkipsCorruptLines() throws {

                                      role: .user, content: "q", timestamp: Date(timeIntervalSince1970: 1), title: nil))
        let url = dir.appendingPathComponent("cursor-s1.jsonl")

            .write(to: url, atomically: true, encoding: .utf8)
        let summary = try XCTUnwrap(try store.scan().first)
        let events = try store.loadMessages(of: summary)
        XCTAssertEqual(events.count, 1)
        XCTAssertEqual(events[0].content, "q")

}

import XCTest
import Foundation

final class RecordE2ETests: XCTestCase {
    private func binPath() throws -> String {
        let out = Process()
        out.executableURL = URL(fileURLWithPath: "/usr/bin/env")
        out.arguments = ["bash", "-lc", "cd \(PackageRoot.path) && swift build --show-bin-path"]
        let pipe = Pipe(); out.standardOutput = pipe
        try out.run(); out.waitUntilExit()
        let data = pipe.fileHandleForReading.readDataToEndOfFile()
        return String(decoding: data, as: UTF8).trimmingCharacters(in: .whitespacesAndNewlines)
    }
    // PackageRoot: 测试文件内推断（#filePath 向上三层到仓库根）

        .appendingPathComponent("cmemo-e2e-\(UUID().uuidString)") }

            #"{"agent":"claude-code","session_id":"e2e","cwd":"/tmp","role":"user","content":"hello"}"#.utf8))

        p.waitUntilExit()

        XCTAssertTrue(FileManager.default.fileExists(atPath: file.path))
        XCTAssertEqual(try String(contentsOf: file, encoding: .utf8)
